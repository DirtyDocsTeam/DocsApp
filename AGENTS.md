# Agent instructions

This file is the compatibility entry point for agents and harnesses that discover `AGENTS.md`, including Codex, DeepSeek Harness, Reasonix, and an OpenClaw agent whose workspace is this repository. The single source of truth for project instructions is [`.agents/AGENTS.md`](.agents/AGENTS.md). Read it before planning or changing this repository.

Do not place project rules in this file. Compatibility adapters for tools with a different native instruction format are listed in [`.agents/adapters.md`](.agents/adapters.md); each adapter delegates back to `.agents/`.
