# QA и тестирование

Раздел для артефактов проверки качества DocsApp: тест-кейсы, чек-листы, отчёты ревью и результаты прогонов
по основному сценарию — конвертации документа с применением стиля и валидацией.

## Что сюда складывать

| Артефакт | Пример |
|---|---|
| Тест-кейс или набор | шаги, ожидаемый результат, привязка к требованию из ТЗ |
| Чек-лист | приёмочная проверка релиза, регресс по конвертации |
| Отчёт о ревью | что проверялось, что найдено, что осталось открытым |
| Результат прогона | сводка по сборке или релизу со ссылкой на CI |

## Ориентиры из требований

- Покрытие тестами основного цикла конвертации — не ниже 70 %.
- Тест-кейсы ведутся в TestRail; цикл работы — ревью требований → покрытие требований → ревью кейсов.
- Автоматический прогон — в CI; браузеры для ручных проверок: Safari, Chromium, Firefox.
- Отдельно проверяются лимиты (10 МБ на файл, 150 МБ на вложения, 100 запросов в минуту) и сроки хранения
  (результат 3 часа, вложения 7 дней).
