## 1. Форматирование текста

Обычный текст.

*Курсив*

_Курсив другим способом_

**Жирный текст**

__Жирный другим способом__

***Жирный курсив***

~~Зачёркнутый текст~~

**Жирный с _курсивом_ внутри**

~~**Жирный зачёркнутый**~~

`Встроенный код`

``Код с `обратной кавычкой` внутри``

Экранированные символы: \* \_ \# \[ \] \!

Специальные HTML-сущности: &copy; &amp; &lt; &gt;

Первая строка  
Вторая строка после жёсткого переноса.

Первая строка\
Вторая строка после переноса через слеш.

Первая строка
Вторая строка того же абзаца.

Новый абзац после пустой строки.

## 4. Маркированные списки

- Первый пункт
- Второй пункт
- Третий пункт

* Элемент через звёздочку
* Второй элемент

+ Элемент через плюс
+ Второй элемент

### Вложенный список

- Первый уровень
  - Второй уровень
    - Третий уровень
      - Четвёртый уровень
  - Второй пункт второго уровня
- Следующий пункт первого уровня

## 5. Нумерованные списки

2. Второй
3. Третий

5. Пятый

1. Первый пункт
   1. Подпункт

   - Маркированный подпункт
   - Ещё один подпункт

1. Первый пункт.

   Дополнительный абзац внутри первого пункта.

2. Второй пункт.

   Ещё один абзац.

## 8. Код

### Встроенный код

Команда `npm install` устанавливает зависимости.

### Блок без указания языка

```
Обычный блок кода
Без языка
```

### Блок с указанием языка

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```

### Python

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

print(hello("GFM"))
```

### JSON

```json
{
  "name": "example",
  "version": "1.0.0",
  "active": true,
  "items": [1, 2, 3]
}
```

### Diff

```diff
- const enabled = false;
+ const enabled = true;
```

### Блок кода с отступом

    Первая строка кода.
    Вторая строка кода.
    Третья строка кода.

## 11. HTML внутри GFM

HTML-элементы могут присутствовать в исходном Markdown,
но результат зависит от фильтрации небезопасного HTML.

Обычный HTML:

<div>
  Пример HTML-блока.
</div>

HTML-комментарий:

<!-- Скрытый комментарий -->

HTML-сущности:

&amp; &copy; &reg; &trade;
