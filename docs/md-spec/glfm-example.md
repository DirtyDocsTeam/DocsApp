## 2. Форматирование текста

Обычный текст.

*Курсив через звёздочки*

_Курсив через подчёркивания_

**Жирный текст**

__Жирный через подчёркивания__

***Жирный курсив***

~~Зачёркнутый текст~~

**Жирный с _курсивом_ внутри**

~~**Жирный зачёркнутый текст**~~

`Встроенный код`

``Код с `обратной кавычкой` внутри``

### Абзацы и переносы

Первый абзац.

Второй абзац.

Первая строка  
Вторая строка после двух пробелов.

Первая строка\
Вторая строка после обратного слеша.

Первая строка
Вторая строка того же абзаца.

### JavaScript

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("GLFM"));
```

### TypeScript

```typescript
interface User {
  id: number;
  name: string;
  active: boolean;
}

const user: User = {
  id: 1,
  name: "Alice",
  active: true
};
```

### Python

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

print(hello("GLFM"))
```
